## 1.PWM 与电机控制

### 1.1 PWM 基本原理

PWM（脉宽调制）通过改变高电平占空比来控制电机转速，输出频率和分辨率由定时器的 ARR 和 PSC 共同决定。

**计算公式：**

 PWM 输出频率 `时钟频率 / (PSC + 1) / (ARR + 1)`
 PWM 占空比  `比较值 / (ARR + 1)` 
 PWM 分辨率 `1 / (ARR + 1)` 

### 1.2 电机驱动参数配置（STM32）

- 方向控制：AIN/BIN（GPIO 引脚）
- 速度控制：PWM 占空比，占空比越大速度越大

**定时器配置：**
只需要调用一个普通计时器即可

### 1.3 核心函数设计

**Set_Pwm 函数的作用：**

| 参数符号 | 对应物理量 | 说明 |
|----------|------------|------|
| `moto > 0` | 正转 | 绝对值 = 油门大小 |
| `moto < 0` | 反转 | 7199 - 绝对值 = 油门大小 |
| `moto == 0` | 滑行停止 | 停车 |

## 2. 舵机控制

### 2.1 SG90 舵机参数

**工作频率：固定 50Hz（周期 20ms）**

| 高电平时间 | 角度 |
|------------|------|
| 0.5ms | 0° |
| 1.0ms | 45° |
| 1.5ms | 90° |
| 2.0ms | 135° |
| 2.5ms | 180° |

### 2.2 控制方式

```c
// 产生一个完整的 20ms 脉冲信号
void set_angle(unsigned int duty) {
    GPIO 输出高电平;
    delay_us(duty);           // 0.5~2.5ms
    GPIO 输出低电平;
    delay_us(20000 - duty);   // 补全剩余周期
}
```
高电平决定转动到的位置，低电平决定在此位置的稳定

## 4. 核心概念对比

### 4.1 直流电机 vs 舵机

| 特性 | 直流电机（L9110S） | 舵机（SG90） |
|------|-------------------|--------------|
| **控制目标** | 转速 + 方向 | 转至固定角度 |
| **PWM 频率** | 可调（常用 1kHz~20kHz） | 固定 50Hz |
| **核心信号** | 占空比 | 高电平脉宽 |
| **方向控制** | AIN/BIN 引脚 | 脉宽数值（0.5~2.5ms） |
