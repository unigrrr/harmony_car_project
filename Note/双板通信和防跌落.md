# UART 双板通信 + 红外防跌落

---

## 一、系统架构

```
┌─────────────────┐   UART(115200)   ┌──────────────────┐
│  Hi3861 主控板   │ ───────────────>  │ STM32F103C8T6   │
│ (OpenHarmony1.0) │ GPIO11 TX → PA10 RX │  (决策执行层)   │
│  · 运动决策       │                  │  · 电机PI闭环      │
│  · 桌沿检测       │                  │  · 编码器反馈      │
│  · TCRT5000×2    │                  │  · WS2812车灯     │
└─────────────────┘                  │  · L9110S驱动     │
                                     └──────────────────┘
```

**分工原则**：Hi3861 负责"想"（传感器判断、运动决策），STM32 负责"动"（闭环控制、实时执行）。

## 二、UART 通信协议（自定义 6 字节帧）

| 字节 | 内容 | 说明 |
|------|------|------|
| 0 | 0xFC | 帧头 |
| 1 | A 方向 | 0=正转 1=反转 |
| 2 | A 速度 | 实际转速 ×100，范围 0~150 |
| 3 | B 方向 | 同上 |
| 4 | B 速度 | 同上 |
| 5 | 0xFD | 帧尾 |

## 三、完成的功能

1. **双板 UART 通信**：Hi3861 发指令帧，STM32 解析执行
2. **路线行驶**：前进 2 秒 → 右转 → 直行 → 左转 → 直行 → 倒车（双线程+互斥锁结构）
3. **PI 闭环电机控制**：增量式 PI，编码器反馈，100ms 控制周期
4. **WS2812 车灯系统**：前大灯（前进亮白色）、倒车灯（后退亮尾部红白色）、左右转向灯（常亮式，灯带左右各 3 颗）
5. **红外防跌落**：TCRT5000 检测桌沿，触发后后退→转向→继续前进

## 四、最终版防跌落逻辑（Hi3861 端）

```
上电停车 2 秒（等 STM32 初始化）
  ↓
循环（每 20ms 巡检）：
  检测到桌沿？
  ├─ 是 → 后退 1.5 秒（固定距离）
  │       → 传感器检查：没安全就继续退（每 50ms 查一次，连续 2 次安全才停）
  │       → 哪边悬空往反方向原地转 1 秒
  │       → 回到循环开头重新检测
  └─ 否 → 低速前进（速度 30）
```

**最终参数**：

| 参数 | 值 | 作用 |
|------|-----|------|
| 前进速度 | 30（0.3 rad/s ≈ 1cm/s） | 慢速巡检，给检测留反应时间 |
| 后退速度 | -80 | 快速脱离桌沿 |
| 转向速度 | ±80 | 原地旋转 |
| 固定后退 | 1.5 秒 | 保证最小后退距离 + 转身余量 |
| 转向时长 | 1 秒 | 实测校准的转角 |
| edge_cnt 阈值 | 2（加权 +2/-1） | 灵敏度与防误触的平衡点 |
