# 鸿蒙小车循迹

## 一、最终状态

赛道流程：起点后 → 岔口1（Y 型，左转）→ 大圈（约 62 秒）→ 岔口2（Y 型，右转）→ 终点停车。


### 最终逻辑（v25）

| 阶段 | 触发条件 | 动作 |
| --- | --- | --- |
| 循迹 | 全程 | 基准 40；压线时内侧轮 10、外侧轮 100 |
| 岔口1 | 0.5 秒内双黑（`FORK_WIN 50`） | 弧线急转左（内侧 0 / 外侧 100） |
| 岔口1 之后 | — | **静默 60 秒**（`SUPPRESS2_TICKS 6000`），期间任何双黑不触发 |
| 岔口2 | 0.7 秒内双黑（`FORK2_WIN 70`，独立可调） | 弧线急转右 |
| 岔口2 之后 | — | 静默 1.5 秒（`SUPPRESS_TICKS 150`） |
| 终点 | 0.3 秒内双黑（`END_WIN 30`） | 停车 |

"X 秒内双黑" = 一侧压黑满 20ms（去抖）后，另一侧在 X 秒内也压黑（含同时双黑）；同一次压线簇只报一次，双白 5 拍后重新待命。

## 二、今天解决的问题（现象 → 根因 → 修法）

### 1. 巡线中莫名其妙后退

- **根因**：旧版安全网是"被动等黑"——N 秒没看到黑线就判定丢线并倒车。但巡线巡得好时，线本来就在两个传感器正中间，**长期双白恰恰是在完美循线**，被误判成"线没了"。
- **修法**：改"主动摇摆探测"——左右轻摆前进，有线必被扫到黑，没线怎么摆都白。

### 2. 大角度转弯误倒车

- **根因**：弯道上一侧传感器长时间压线，被"骑岔路线"检测误认为岔口 → 往反方向转 → 离线 → 倒车。
- **修法**：路口检测加互证——单侧长压线必须"另一侧在窗口内也压过线"才算路口（真 Y 岔两侧都会压，纯弯道只压一侧）；先后压线配对要求两侧脉冲都够长（弯道过冲的第二侧很短）。


### 3. 岔口转向反应太慢

- **修法（两侧配合）**：
- Hi3861：转入改急——内侧 0 / 外侧 100，找线段 200ms→120ms；
- STM32：加"目标突变助推"——新指令到达立即 ±1500 PWM，不等 PI 爬升（纠偏 40~100 的突变都能触发）。

### 4. 第二个岔路口直接停车

- **根因**：停车只在"等终点"状态发生，说明岔口2 的名额被提前用掉——大圈上的弯道在长窗口下误配对了双黑。
- **修法**：岔口1 转完后加静默期，期间任何双黑都不算岔口2；日志加时间戳便于定位。
- **标定结果**：大圈实测约 **62 秒**，静默期定为 **62 秒**刚好盖住。

## 三、关键参数速查（tracking.c v25）

| 参数 | 值 | 说明 |
| --- | --- | --- |
| `SPD_BASE` | 40 | 巡线基准速度 |
| `CORRECT_LO / HI` | 10 / 100 | 纠偏手感（用户上传历史版标定） |
| `CAP_INNER / OUTER` | 0 / 100 | 岔口急转 |
| `FORK_WIN / FORK2_WIN / END_WIN` | 80 / 100 / 30 | 岔口1 / 岔口2 / 终点双黑窗口（×10ms） |
| `SUPPRESS2_TICKS` | 6200 | 岔口1后静默 62 秒 |
| `SUPPRESS_TICKS` | 150 | 岔口2后静默 1.5 秒 |
| `BLACK_DB` | 2 | 压黑确认 20ms 去抖 |
| `TRIM_A / TRIM_B` | 100 / 100 | 左右轮个体差异补偿 |
